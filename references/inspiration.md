# Design inspiration sites

Websites to suggest, or browse yourself, when the user wants a good-looking page but has no concrete reference. They are grouped by need. Each site was checked to resolve on 2026-11-25.
Start with the first site listed in the group that matches the page type, unless the user names a direction.

## How to use this

1. **Ask first, briefly.** Ask one question about the direction the user likes, for example "Minimal and editorial, bold marketing, dense dashboard, or playful?" If they already gave a mood or a reference, skip this step.
2. **Offer 3–5 sites that match the page type.** Use the groups below. A report or dashboard gets data-viz and product-UI sites. A landing page gets marketing galleries. Docs and articles get editorial and typography sites. Let the user pick a few examples they like.
3. **Browse yourself if you have a browser tool.** Open 2–3 matching sites, look at several examples, and summarize the shared traits you will follow: layout rhythm and grid, type scale and pairing, density, color mood, use of imagery, motion level. Some galleries block automated browsers with bot checks. Skip those instead of trying to get around them.
4. **Take direction, never content.** Don't copy a specific site's design, layout or assets wholesale. Don't reuse its copy, logos, illustrations, photos or fonts you have no license for, and don't hotlink anything. The page must work offline. Translate what you saw into this skill's stack: shadcn style choice, theme tokens (see `color-tools.md`), Tailwind spacing and type scale, and components from `components.md`.
5. **Credit is not needed for direction**, but if the user points to one exact site as "make it like this", say you will follow its feel, not clone it.
